# InEKKapp

v1.0.2

## Dependencies

- streamlit
- fluprodia
- plotly
- matplotlib
- numpy (comes with fluprodia and streamlit)
- CoolProp (comes with fluprodia)
- pandas (comes with plotly and streamlit)

## Setup and run

- Install python and all dependencies
- run ``streamlit run app.py``
- alternatively run streamlit as a python module ``python -m streamlit run app.py``
- See [streamlit documentation](https://docs.streamlit.io/develop/concepts/architecture/run-your-app) for more details
